# Bexon

React + Vite + Tailwind + Flowbite + GSAP.

    npm install
    npm run dev

Every dashed teal box is an image slot: replace `<Slot label="..." />` with
`<img src="/your-image.jpg" className="h-full w-full object-cover" alt="" />`.
Put images in `public/` and reference them as `/name.jpg`.
